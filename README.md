AI-Powered LinkedIn Content Automation Agent 🤖
This project showcases an automated workflow that generates and publishes professional LinkedIn posts using AI. By leveraging Make.com, Google Sheets, and the Gemini API, I've streamlined my content creation process to save hours of manual work every week.

🚀 How it Works
Input: I add a topic to a Google Sheet.

Processing: An automated agent picks up the topic and processes it through the Gemini API.

Drafting: The AI generates a professional and engaging LinkedIn post based on the topic.

Publishing: The system automatically publishes the post directly to my LinkedIn profile.

Tracking: The status in the Google Sheet is updated to "Posted" automatically.

🛠 Tech Stack
Automation Platform: Make.com

AI Model: Google Gemini API

Database: Google Sheets

Platforms: LinkedIn

📈 Impact
Efficiency: Saves hours of manual work every single week.

Consistency: Maintains a professional presence on LinkedIn with minimal human intervention.

Innovation: This is a core component of my journey toward building Mega AI.
